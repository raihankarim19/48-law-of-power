# 48 Hukum Kekuasaan — Dibaca Ulang

Aplikasi belajar interaktif dalam Bahasa Indonesia tentang *The 48 Laws of Power* karya Robert Greene, diceritakan ulang dengan parafrase sendiri. Setiap hukum dibahas lewat kisah sejarah, gambar beranimasi, demo yang bisa dicoba, catatan koreksi sejarah, contoh dunia kerja dan bisnis, serta bagian "tameng" untuk mengenali dan melindungi diri dari taktik manipulatif.

**Buka online:** https://raihankarim19.github.io/48-law-of-power/

Seluruh aplikasi berada dalam satu file `index.html` dan bisa juga dibuka langsung di browser tanpa internet. Progres belajar tersimpan di browser masing-masing pembaca.
